# Brokerstars

Simulador de vida de joven millonario en una torre: banco y MegaMart abajo,
negocios y la Planta Gris en medio, casino arriba. Hecho con Three.js.

```bash
npm install
npm run dev      # juego en http://localhost:5173 · creador en /creador.html
npm run build    # versión final en dist/
```

**Controles:** WASD moverse · Shift correr · arrastrar el ratón para girar la
cámara · rueda para acercar · E interactuar · I inventario · Esc cerrar.
En el móvil hay joystick y botones táctiles.

Diseño completo y hoja de ruta: [docs/GDD.md](docs/GDD.md).
